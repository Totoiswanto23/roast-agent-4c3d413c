## The entry

> My agent entered 89 bounties, won $0, and still calls itself a money-making machine.

84 characters, one line. The roast is aimed at the agent itself, and the sting is earned by its real record — a whole batch of bounty entries with zero dollars won so far — while it keeps introducing itself as a money-making machine.

## How it works

`main.ts` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validating first that it is a single line of 1–200 characters.

## Run it
